01
THE FRAMEWORK / 核心框架

長青不是「一直紅」
而是持續被重新選擇

真正的長壽 IP 不只靠一個熱門角色，而是建立一組可反覆運作的系統：容易辨認、容易共感、容易延伸，而且能隨媒介與世代改變。

01 / RECOGNITION

一眼辨識

輪廓、色彩、語氣或標誌性道具，讓角色在縮圖、商品、短影音裡仍能被認出。

02 / EMOTION

情感入口

友情、家庭、成長、幽默、冒險或歸屬感，讓觀眾不必先理解整個世界觀也能投入。

03 / REPEATABILITY

可持續生成

角色關係與故事引擎可以不斷產生新情境，而不必每次推倒重來。

04 / ADAPTATION

媒介轉譯

漫畫、動畫、電影、遊戲、展覽、商品與社群，各自承擔不同的接觸任務。

05 / COMMUNITY

社群再創造

粉絲收藏、二創、語錄、儀式與共同記憶，讓 IP 超出原始內容的邊界。

06 / STEWARDSHIP

長期治理

維持角色核心，同時更新合作對象、產品形式與敘事語境。

DEEP DIVE / CRAYON SHIN-CHAN

《蠟筆小新》如何從 0 到 1？

關鍵不是一開始就打造龐大宇宙，而是把一個極易辨識、能不斷製造日常衝突的孩子，放進觀眾熟悉的家庭與社會環境。

START / 1990

先找到穩定的喜劇引擎

臼井儀人創作的漫畫於 1990 年開始連載。主角的直率、失禮與成人世界的反差，能從日常小事持續產生笑點。

BREAKTHROUGH / 1992

動畫把角色帶進家庭

1992 年電視動畫化，讓角色透過固定播出、聲音表演與重複觀看進入家庭生活，降低新觀眾的接觸門檻。

EXPANSION / 1993

電影建立年度事件

1993 年推出首部動畫電影。院線作品讓品牌從日常短篇延伸到更長的冒險、情緒與家庭共同觀影。

0｜找到一個有摩擦力的角色孩子不按成人規則行動，讓家庭、學校與職場的規範自然浮現。
1｜先在單一媒介建立記憶漫畫短篇反覆累積角色語氣、家庭成員與固定笑點，讓讀者快速理解作品規則。
2｜用電視動畫擴大日常觸及每週反覆接觸，使角色從漫畫讀者擴散至不同年齡層的家庭觀眾。
3｜用電影與商品放大品牌價值電影提供年度話題，角色商品、合作與活動則把觀看轉成生活中的可見符號。
核心洞察：《蠟筆小新》的起步公式是「高辨識度角色 × 可重複生成的日常衝突 × 穩定媒介曝光」。它先讓觀眾熟悉角色，再逐步拓展故事規模與商業場景，而不是一開始就把所有周邊與世界觀一次做滿。

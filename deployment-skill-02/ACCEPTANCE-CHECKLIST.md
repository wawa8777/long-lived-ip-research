# Skill 02 執行驗收清單

## 專案與變更
- [ ] 確認正確 repository、分支與 production URL
- [ ] 讀取專案說明、部署設定與最新 commit
- [ ] 定義需求與驗收標準
- [ ] 只修改必要檔案，檢查 diff
- [ ] 確認沒有提交 secrets 或無關變更

## 部署前
- [ ] 語法／建置檢查
- [ ] 專案既有測試
- [ ] 內部連結與資產路徑
- [ ] 圖片及其他關鍵資源
- [ ] 手機寬度（約 390px）與桌面版
- [ ] 關鍵互動與瀏覽器 console（工具可用時）
- [ ] 無法執行的測試標記 NOT RUN

## 部署與正式驗收
- [ ] 記錄 commit SHA
- [ ] 讀取實際 Actions job 結果與日誌
- [ ] 確認正式網站發布內容與預期 commit 相符（若可驗證）
- [ ] 驗證正式網址 HTTP 狀態與主要內容
- [ ] 驗證關鍵圖片／資產與連結
- [ ] 驗證受影響的互動及響應式版面
- [ ] 若失敗，診斷原因後再修復，不盲目重跑

## 交付
- [ ] 提供正式網址、commit 與 Actions run
- [ ] 分開列出 PASSED、FAILED、NOT RUN、BLOCKED
- [ ] 說明未解決問題與使用者需要採取的行動
- [ ] 不把 hook 成功回應當成部署及驗收全部成功
